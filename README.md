## نصب

1. فایل `danishgah.apk` را دانلود کنید و باز کنید.
2. اگر گوشی اجازه‌ی نصب نداد، گزینه‌ی «نصب برنامه‌های ناشناس» را برای مرورگر یا فایل‌منیجر فعال کنید.
3. نصب را تأیید کنید. نسخه‌های بعدی روی همین نسخه نصب می‌شوند.

## نسخه‌ی فعلی: دمو

این نسخه با داده‌ی نمونه کار می‌کند تا همه‌ی امکانات بدون سرور قابل امتحان باشد:

- **ورود:** هر شماره موبایل معتبر + کد تأیید `11111`
- **خرید:** درگاه آزمایشی است و پرداخت واقعی انجام نمی‌شود
- **کدهای تخفیف نمونه:** `WELCOME` و `BOOK50`
